# Portfolio Generator

Générateur de portfolio dynamique — un unique fichier HTML autonome (`index.html`), sans framework ni backend.

## Utilisation

1. Ouvrez `index.html` dans un navigateur (aucune installation, aucun serveur requis).
2. Remplissez le formulaire à gauche : profil, liens sociaux, compétences, projets.
3. L'aperçu à droite se met à jour en temps réel.
4. Téléchargez le résultat :
   - `index.html` et `style.css` séparément, ou
   - un `.zip` contenant les deux fichiers (généré directement dans le navigateur, sans dépendance externe).
5. Déployez les fichiers générés tels quels sur Netlify, Vercel, GitHub Pages, etc.

Toutes les données saisies restent en mémoire dans le navigateur — rien n'est envoyé à un serveur.
